# NEXUS Portfolio

Frontend-only developer portfolio: cybersecurity operations aesthetic, repository network, and interactive 3D scenes.

## Stack

React · Vite · TypeScript · Tailwind CSS · Three.js · React Three Fiber · GSAP · Lucide

## Scripts

```bash
npm install
npm run dev
npm run build
```

Mock data lives in `src/data` and is accessed through `src/services` so a REST API can replace it later without rewriting UI components.
